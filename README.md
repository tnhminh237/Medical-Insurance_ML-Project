# Medical-Insurance-ML

Cấu trúc dự án ML: EDA, preprocessing, regression, classification, XAI và Streamlit.

**Lưu ý:** Đây là bộ khung dự án. `data/insurance.csv` hiện là file trống để giữ đúng cấu trúc; thay bằng dữ liệu thật trước khi chạy. Notebook và code Python mới là file khởi tạo, chưa triển khai các mô hình.
